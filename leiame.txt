Trabalho 2 - Tecnicas de Programacao 2 (CIC0198) - UnB
Sistema de monitoramento de logs com TDD

==============================================================================
PRE-REQUISITOS
==============================================================================
- g++ (com suporte a C++14)
- make
- valgrind        (verificador dinamico)
- cppcheck        (verificador estatico)
- cpplint         (estilo Google; instalar via: pipx install cpplint)
- doxygen         (geracao de documentacao)
- gcov            (acompanha o gcc)

==============================================================================
COMPILACAO E EXECUCAO
==============================================================================
No diretorio raiz do trabalho, executar:

  make            - compila o binario de testes
  make test       - compila e roda os testes
  make coverage   - roda testes com cobertura (gera monitora_logs.cpp.gcov)
  make valgrind   - roda os testes sob o Valgrind
  make lint       - verifica estilo com cpplint
  make check      - analise estatica com cppcheck
  make doc        - gera documentacao HTML em doc/html/index.html
  make clean      - remove artefatos de build
  make distclean  - clean + remove documentacao gerada
